聊天线路、时间、天气与主动消息

- 设置中的两条备用线路独立保存 API 地址、Key、模型、输出上限和记忆选项；原线路自动保留。切换按钮只允许一条当前聊天线路。获取模型、测试线路均使用所在卡片的 Key，不会切换当前聊天线路。
- 每次向订阅或备用模型请求时，注入服务器当前年月日、星期、时分秒和时区，历史消息带时间。聊天顶端显示日期和时分。默认时区 Asia/Shanghai，可编辑。
- 天气默认乐陵（山东），可以手动查询城市或点击手机定位。定位须浏览器授权；仅保存保留两位小数的地区坐标。天气查询通过 Open-Meteo，30分钟缓存；失败回退为天气未知，不编造。
- 天气来源及接口文档：https://open-meteo.com/、https://open-meteo.com/en/docs、https://open-meteo.com/en/docs/geocoding-api。个人非商业站使用免费接口，按官网要求展示归属。
- 服务器每分钟检查主动消息资格，网页关闭也会运行。使用当前聊天线路、同一聊天历史和时间/天气。不会把生成任务伪装成用户发来的消息写入数据库。模拟拉黑、正在生成或整理记忆、用户刚发消息时跳过。
- 用户要求的配置：全天、每日最多10次尝试、空闲60分钟后考虑、两次至少相隔120分钟。不是保证每天发满10条。失败也计入上限，不会立即重试；次数、发送时间、失败状态存入SQLite，重启不清零，也不追补漏发。
- 主动消息保存到原聊天记录。网页可见时每20秒查看新消息，回到页面时也检查。此版本没有系统 Web Push，所以不提供 iPhone 锁屏通知。
- 后端默认保持主动消息关闭，生产部署后依据本次明确请求开启；测试应用也默认关闭，不会意外调用真实模型。
- 自动数据备份包含 SQLite 和 uploads，因此新增设置和主动消息也会备份。API Key 不进入 GitHub。

验证：test-chat-routes.cjs、test-presence.cjs、既有识图/表情/背景回归；隔离全栈浏览器测试确认双线路、模型列表、未保存草稿保护、定位、城市、保存刷新、小屏布局和关闭浏览器后只生成一次主动消息。
