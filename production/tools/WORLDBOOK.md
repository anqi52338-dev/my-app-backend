# 世界书

入口位于聊天输入框下方的书册图标，以及设置中的“世界书”。

最多保存 50 本世界书、30 套组合方案；可编辑名称与正文。选择启用方案后点击“保存全部修改”。一个方案可选择多本书，同一本可被多个方案引用。取消启用保留所有内容。删除书时移除方案引用，删除当前方案时关闭世界书。

数据保存于 SQLite KV 的 worldbook 项，纳入服务器加密数据备份和 /api/export JSON；不纳入源码仓库。PUT /api/worldbook 使用 revision 防止多页面覆盖，回复和记忆整理期间拒绝修改。只有当前启用方案的非空内容进入主聊天和主动消息系统上下文；无痕/模型测试等独立窗口不读取。订阅线路的有效设定变化触发下轮重开会话。正文处于稳定缓存前缀中，不含当前时间。每本 20000 字，总存储 40 万字，启用内容序列化合计 24000 字上限；不会截断后悄悄丢失设定。

验证：node tools/test-worldbook.cjs。手机界面、真实 HTTP 保存/重载/冲突/认证/导出和模型请求通过本地模拟接口测试；未消耗用户 API 余额。
