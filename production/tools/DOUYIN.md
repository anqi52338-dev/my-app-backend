# 他的抖音

聊天输入框下播放图标，设置里“他的抖音”。默认开启每6小时一次的空闲浏览及允许聊天分享，自动发布默认关闭，可在专页保存开关开启，默认北京时间19点后每天最多一次发布尝试。主动分享复用 presence 的空闲/间隔/每日次数，不单独加发。遇验证码/登录失效停止读内容，不自动解决验证码。

KV douyinPrefs/douyinState 保存设置、30条浏览卡片、20篇草稿和操作记录，纳入现有SQLite加密备份和/api/export。所有阅读数据仅是可见卡片标题/简介，不宣称完整看懂视频画面/音频。分享记录链接去重。每分钟最多手动浏览/分享一次。每天最多5次草稿生成、一次发布尝试；发布前保留状态，结果不明不重试，关闭自动发布，需检查作品列表。自动任务只在主聊天空闲且未拉黑时执行，关网页/电脑不影响服务器。

公开创作使用独立提示与公开灵感，不把人设、私聊、记忆库、定位天气带进生成请求。原创文字通过Pillow生成720x960卡片，上传到图文编辑器，选择“内容由AI生成”声明，再发布。不是AI视频生成器，不搬运他人视频。不会自动点赞/评论/私信。自动发布关闭时可先生成查看草稿、手动点击发布。

服务器依赖：Python playwright/Pillow、Chrome、中文字体及独立浏览器 systemd ourhome-douyin-desktop.service。服务脚本 tools/douyin-desktop.py，实际 /home/ubuntu/.local/share/ourhome-douyin/desktop.py；profile/cookies仅在服务器私有目录(700/600)，不入Git。Xvfb:95/x11vnc5907/noVNC3198/CDP3199均仅loopback。Chrome会话需用户亲手完成验证。SSH仅用于临时人工桌面连接，任务通过本机CDP无需个人电脑。

验证：test-douyin.cjs 为本地模拟，覆盖去重/限流/不确定暂停/不重试。手机实际HTTP/浏览器测试覆盖入口、设置、草稿持久化、认证、无私聊人设/记忆进入公开请求、无横向溢出。线上采集真实卡片已验证；真实上传/AI声明为dry-run，不提交测试作品。正式发布需以平台成功提示为准，不能把点击按钮当作成功。
