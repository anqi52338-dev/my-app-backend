# 模型对小手机功能的了解

`app-capabilities.js` 保存简短的已实现功能清单，并从实际设置生成当前状态：主动消息开关、每天上限/间隔/时段、当前聊天线路、两条API是否配置、朗读配置和天气开关。只传必要标志，不传API Key、人设原文、位置或私人记录。

每次实际模型请求动态注入：普通订阅聊天、备用API、主动消息、角色独立窗口和游戏角色回答。不写入用户聊天、长期记忆或自定义人设，不会因记忆压缩丢失；改变开关或线路后，下一次请求使用最新状态。

提示模型区分“已实现”“当前关闭”“待配置”，提新功能前检查已有清单；配置操作仍由用户在页面执行，不能谎称已经通过聊天改设置。实时通话与iPhone锁屏推送尚未接入。只在涉及功能的话题中自然使用，不在日常聊天背诵清单。

以后增加或移除实际功能时，应同步更新这个清单。新增状态字段只通过白名单标志传递，不直接序列化整个配置对象。
